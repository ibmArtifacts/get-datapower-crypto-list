# get-datapower-crypto-list
Creates a csv file of all the crypto key and cert objects from a datapower gateway across all domains

Usage:
```
./list_dp_crypto.sh                 # prompts for host, port, user and password
./list_dp_crypto.sh inventory.csv   # choose the CSV name
DP_HOST=dp1 DP_PORT=5554 DP_USER=admin DP_PASS=... DP_DOMAINS="default apiconnect" ./list_dp_crypto.sh
```
